📦 Companion-Modul (Stream Deck)

Für komfortable Stream-Deck-Bedienung mit Live-Status auf den Buttons gibt es ein passendes Companion-Modul.

  1. Modul herunterladen (~450 KB):
    ⬇ Auf GitHub Releases öffnen
  2. In Companion: Modules → Import module package
  3. Die heruntergeladene .tgz-Datei auswählen
  4. Connections → + Add connection, nach "Soundboard" suchen und hinzufügen
  5. Konfigurieren:
    • Bridge Host / IP: localhost (oder IP des Soundboard-PCs)
    • Bridge Port: 8765
  6. Im Companion-Presets-Tab erscheinen jetzt alle Pads als Drag&Drop-Buttons
